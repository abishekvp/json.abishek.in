# JSON Master Studio — `json.abishek.in`

A professional, fullscreen, browser-based JSON powerhouse:
- **Format & Validate:** 2 Spaces, 4 Spaces, Tab, Minify/Compact, Alphabetical key sorting (A-Z), and real-time syntax error locator.
- **✨ Auto-Repair JSON:** 1-click fixes for unquoted keys, single quotes, trailing commas, Python literals (`None`, `True`, `False`), and comments.
- **Interactive Tree Inspector:** Searchable, collapsible object/array tree visualizer with 1-click JSONPath copying and type badges.
- **Multi-Format Converters:** Convert JSON to TypeScript interfaces, CSV spreadsheets, YAML, XML, Go structs, and Python dataclasses.
- **JSONPath Query:** Filter and query deeply nested structures with live evaluation.
- **JSON Diff:** Side-by-side recursive comparator highlighting additions, deletions, and property modifications.
